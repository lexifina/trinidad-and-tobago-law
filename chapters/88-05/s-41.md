(a) fails to make such return within the time specified for

(b) makes or causes to be made any such return which he

(c) on being so required, fails to give any information or
explanation respecting the return which it is in his power to give, is guilty of an offence against this Act, and such offence so long as the default continues shall be deemed to be a continuing offence.
