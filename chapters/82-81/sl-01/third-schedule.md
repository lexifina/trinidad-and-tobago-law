# THIRD SCHEDULE (rules 5, 17)
CLASSIFICATION OF GOODS
Class 1
Chemical substances used in manufactures, photography or
philosophical research, and anti-corrosives.
Class 2
Chemical substances used for agricultural, horticultural,
veterinary and sanitary purposes.
Class 3
Chemical substances prepared for use in medicine and pharmacy.
Class 4
Raw, or partly prepared, vegetable, animal and mineral
substances used in manufactures, not included in other Classes.
