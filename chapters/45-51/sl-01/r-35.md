# 35. Hearsay evidence. [37/1981].
(1) R.S.C. Order 38 rules 20 to 33, shall apply in relation to a defended cause as if in rule 21 for the reference in subparagraph (4) to Order 41, rule 5 there were substituted a reference to rule 32 of these rules.
(2) Unless in any particular case the Court otherwise directs R.S.C. Order 38, rule 21(1) shall not apply in relation to an undefended cause pending in the Court.
